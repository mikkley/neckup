# TurtleUp 游戏化系统设计（像素打怪版）

> 2026-08-07 · 依据前期调研结论设计（调研存档未公开）
> 世界观一句话：**低头久坐会催生「僵硬怪」，你用脖子当武器，在每个番茄钟休息时把它们打跑，战利品浇灌山谷里的山峰。**

---

## 1. 设计原则（不可违反）

1. **安全白名单**：游戏只识别单轴、限幅度、慢速动作；参数硬顶见 §7，任何玩法不得诱导突破。
2. **番茄钟稀缺**：微游戏只在 5 分钟休息段出现，工作时间锁死；没有"再玩一局"按钮——运动上限由产品架构强制执行。
3. **无惩罚**：不掉血条式焦虑、不断签清零、无稀有度掉落、无排行榜；失败只有鼓励。
4. **声效即到位提示**：每个动作做到位必有声音确认（用户戴着 AirPods，声音是天生的私有反馈通道）。
5. **风格统一**：8-bit 像素风（pacman 设计系统 token），怪物和动作都是像素画；文案温和幽默。

## 2. 世界观与包装

- 玩家是**像素山谷的守护者**，山谷中央有一座随专注生长的山峰（沿用 PRD G2/G3）。
- 久坐低头会让山谷里刷出**僵硬怪（Stiffies）**——它们是"僵硬"的化身，被打跑的方式不是点屏幕，而是**活动你的脖子**。
- 每次番茄钟休息 = 一次**随机遭遇战**：洗牌式从 5 只怪物中抽一只，30–60 秒一局。
- 打赢的怪物进入**怪物图鉴**；战利品（像素水滴/阳光）浇灌山峰。
- 吉祥物乌龟「慢慢」是新手引导员 + 第 4 个游戏的主角。

## 3. 五个动作 × 五只怪物（核心映射表）

| # | 怪物 | 舒展动作 | 输入轴 | 目标肌群 | 锻炼参数（医学依据） |
|---|---|---|---|---|---|
| M1 | 石斧史莱姆 | 缓慢点头（前屈–后伸） | pitch | 颈椎屈伸活动度 | 前屈≤30°/后伸≤20°，每往复约 4s |
| M2 | 双头甲虫 | 左右转头 | yaw | 颈椎旋转 | 每侧≤40°，到位保持 3s |
| M3 | 天平水母 | 侧颈拉伸 | roll | 上斜方肌 | 每侧≤30°，静态保持 10–30s |
| M4 | 气功龟「慢慢」 | 收下巴 chin tuck | pitch 微幅模式 | 深层颈屈肌（治头前伸） | 保持 5s×10 次 |
| M5 | 斜月蝙蝠 | 低头转肩看（复合） | pitch+yaw（降幅度） | 肩胛提肌 | pitch≤20°+yaw≤25°，保持 10–30s |

设计要点：**每只怪物只考验一个动作**，输入就是康复动作本身，玩 60 秒 = 做完一组医学推荐的舒展。

## 4. 分游戏详细设计

### M1「石斧史莱姆」— 点头劈砍（pitch）

- **玩法**：像素台阶从上方缓缓降下石斧史莱姆；**缓慢低头 = 斧劈下**，**缓慢仰头 = 抬斧**。劈中即消灭。节奏对齐"每个往复约 4 秒"的医学基准——劈砍窗口约 2 秒，逼你慢。
- **到位判定**：pitch 从校准零点下行 ≥25° 且角速度 ≤30°/s 记一次"劈"；回到 -5° 以上完成一个往复。>60°/s 判甩头，史莱姆"被吓跑"（不计分，提示"慢一点 🐢"）。
- **一局**：60 秒 ≈ 10–12 个往复 ≈ NHS 推荐一组。
- **声效**：劈中 = 木质劈裂短音 + 上行两音确认（<300ms）；连续劈中 combo 音高五声音阶递增；甩头 = 低音量钝音 thunk。
- **视觉**：史莱姆被劈成两瓣像素块，8-bit 粒子溅射。

### M2「双头甲虫」— 左右格挡（yaw）

- **玩法**：甲虫从屏幕左/右边缘**缓慢**逼近（预告方向有明显前摇动画 1.5s）；**转头注视来怪方向 ≥30° 即举盾格挡**。交替出现，间隔逐渐缩短但保证"到位保持 3s"的医学节奏。
- **到位判定**：|yaw| ≥30°（硬顶 40°）且速度 ≤30°/s，保持 ≥1.5s 记一次格挡。
- **一局**：45–60 秒 ≈ 左右各 5–8 次。
- **声效**：格挡 = 金属闷响"铛"+ 确认音；怪物逼近有渐近的像素脚步声（空间感预告方向，降低对屏幕的依赖）。
- **边界**：绝不要求快速左右甩（RidePods 教训）；间隔下限锁死 3 秒。

### M3「天平水母」— 侧屈接物（roll）

- **玩法**：头顶一只托盘，像素宝石从上方左右随机飘落；**侧屈倾斜托盘接住**。大宝石落地前会"悬停"5 秒——**保持侧屈姿势顶住它**即完成一次静态拉伸（对齐 10–30s 保持推荐的下限）。
- **到位判定**：|roll| ≥20° 移动托盘；|roll| ≥25° 保持 ≥5s 记一次"定住"（硬顶 30°）。
- **一局**：60 秒 ≈ 接物若干 + 左右各 1–2 次静态保持。
- **声效**：接宝石 = 清亮"叮"（音高随 combo 递增）；大宝石悬停时播放持续蓄能音（音高缓慢上行，撑满即"迸发"琶音）——**用声音倒计时替代盯屏**，这是 sonification 的最佳应用点。

### M4「气功龟慢慢」— 收下巴蓄力（chin tuck）

- **玩法**：吉祥物慢慢示范"挤出双下巴"，玩家跟做：蓄力条随收下巴姿态填充，保持 5 秒蓄满，发射气功波打散一团"僵硬云"。一局 60 秒 ≈ 6–8 次（对齐保持 5s×10 次的处方下限）。
- **到位判定（技术风险最高，需实测）**：chin tuck 在 AirPods 上表现为 pitch 微幅变化（约 5–10°）。判定方案：检测"pitch 小幅下探 3–8° 后回收到零位附近并保持 ≥3s"的模式；**降级方案**：若实测识别率差，改为"极小幅缓慢点头蓄力"，文案不变。
- **声效**：蓄力 = 上升滤波 sweep（音高随蓄力条连续上行——这里动作慢、幅度小，连续 sonification 的蓝牙延迟不敏感）；发射 = 短促爆发音 + 胜利琶音。
- **包装**：慢慢是唯一的"友军怪"，打输也没有失败态，只有"慢慢再教你一遍"。

### M5「斜月蝙蝠」— 斜向瞄准（pitch+yaw 复合，降幅度）

- **玩法**：蝙蝠群从斜上方飞过，**低头约 15° 并转向一侧**瞄准（鼻尖朝腋下方向），准星稳定 1 秒自动放箭。对齐肩胛提肌拉伸的"低头转肩看"。
- **到位判定**：pitch 10–20° + yaw 15–25° 的复合区间（幅度减半，遵守"复合动作降幅度"原则），稳定 ≥1s 记一次命中。
- **一局**：45–60 秒，左右交替。
- **声效**：瞄准锁定 = 短"锁链咔哒"；放箭 = 弦响；命中 = 下行滑音（蝙蝠坠落，"音高下降=下落"惯例）。

## 5. 随机遭遇与长期机制

### 5.1 随机轮换规则

- **洗牌式抽取**：5 只怪洗成一队，抽完一轮重新洗；保证每个舒展动作均匀覆盖，避免纯随机导致某动作长期缺席。
- **每日推荐**：每天随机高亮一只"今日头目"（击败得双倍水滴），次日该怪仍在池中——有稀缺感无 FOMO。
- **工作时间锁死**：非休息段点开游戏入口只显示"怪物们在你专注时不敢来 🐢"。

### 5.2 长期进度机制

| 机制 | 设计 | 依据 |
|---|---|---|
| 怪物图鉴 | 每只怪 3 个熟练度星级（累计击败 1/10/30 次点亮）；集满全图鉴 3 星解锁非稀有纪念徽章 | Zeigarnik + SDT 胜任感；不设限时不设稀有度 |
| 山峰成长 | 每次胜利得水滴浇灌山峰：秃山→青山→雪峰；连续断更缓慢枯萎（佛系模式可关） | PRD G2/G3 + 目标梯度 |
| 累计舒展天数 | **用累计天数替代连续 streak**——断了不清零，只显示"山谷等你回来" | 防断签焦虑（调研 3.3） |
| 每日任务 | 3 个轻任务：「完成 2 个番茄」「低头 <10 次」「打跑 1 只怪」 | 多邻国 Daily Quests 本地化 |
| 成就 | 「首座雪峰」「全图鉴」「单周低头次数减半（和上周的自己比）」；解锁时岛屿 0.8s 庆祝动画 | 自我竞赛替代排行榜 |
| 难度自适应 | 根据历史表现微调目标角度/节奏，保持"差一点满分" | 心流三要素 |

### 5.3 休息段完整流程（5 分钟）

```
番茄结束通知 → 岛展开为 ~360×260pt 游戏窗
  → 第 1 分钟：随机遭遇战（本设计 5 选 1）
  → 第 2–4 分钟：游戏窗收回，语音提示"起来走走 / 肩胛收缩 10 次"（传感器测不到的动作只做引导计时）
  → 最后 30s：远眺提示 + 下一番茄倒计时
```

## 6. 声效规范

### 6.1 通用事件音效表

| 事件 | 音效 | 时长 |
|---|---|---|
| 动作到位 | 上行两音确认 | <300ms |
| combo 递增 | 五声音阶逐级上行 | <200ms/级 |
| 断 combo / 失败 | 低音量钝音 thunk | <250ms |
| 甩头警告 | 更轻的提示音 + 文案"慢一点 🐢" | <200ms |
| 一局胜利 | 上行琶音 | <800ms |
| 图鉴点亮 / 成就 | 8-bit 庆祝短句 | <1s |
| 蓄力类持续反馈 | 音高随进度连续上行（sonification） | 跟随动作 |

### 6.2 到位渐进反馈：棘轮音（核心听觉范式）

**设计来源**：用户提出的「拨动转盘」直觉——与 Apple Watch 数码表冠的棘轮反馈、盖革计数器的接近度提示同构。用途：头部动作**接近目标角度的过程中**，让用户不用看屏幕就知道"快到位了"。

**规则**：
- 定义接近度 `p = (当前角度 − 起始角度) / (目标角度 − 起始角度) ∈ [0, 1]`。
- 每跨过 10% 进度播一次**棘轮咔哒**（短促、干燥、<80ms，像拨动机械转盘）；咔哒音高按半音阶随 p 上行——越接近目标越"高、亮"。
- 最后 20%（p ∈ [0.8, 1.0]）咔哒加密为每 5% 一次，制造"冲刺段"紧张感。
- `p` 到达 1.0 → 播放 §6.1 的"到位确认音"收尾；中途回退超过 15% 则静默回退，不播反向音（避免惩罚感）。
- **为什么用离散咔哒而非连续音高**：每次咔哒是独立事件，对 AirPods 126–274ms 蓝牙延迟不敏感（用户感知的是"进度档位"而非实时跟踪）；连续 sonification 只保留给 M3/M4 的慢速蓄力场景。

**各游戏应用**：
| 游戏 | 棘轮音用途 |
|---|---|
| M1 石斧史莱姆 | pitch 接近劈砍阈值（25°）时逐级咔哒，到位=劈裂音 |
| M2 双头甲虫 | 转头接近格挡角度（30°）逐级咔哒，到位=盾挡"铛" |
| M3 天平水母 | 移动接物用棘轮音；大宝石静态保持保留连续蓄能音 |
| M4 气功龟慢慢 | 保留连续蓄力 sweep（动作慢，延迟不敏感） |
| M5 斜月蝙蝠 | 接近复合瞄准区间逐级咔哒，锁定="锁链咔哒"+放箭 |

### 6.3 技术方案

- **AVAudioEngine 常驻引擎 + 全部音效预载 `AVAudioPCMBuffer`，`scheduleBuffer` 即时触发**（不用 NSSound）。
- 音效资产：8-bit 芯片音，程序生成（如 [sfxr](https://www.drpetter.se/project_sfxr.html) 类工具）或 CC0 音效包，仓库内自包含。
- 事件驱动为主；连续 sonification 只用于 M3/M4 的慢速蓄力场景（AirPods 蓝牙延迟 126–274ms，快速映射会有滞后感）。
- 声音路由跟随 AirPods；耳机断开回退纯视觉；**检测屏幕共享/会议自动静音**（仿 Muzzle）。
- 设置项：音效总开关、音量滑条（默认 60%）。

## 7. 安全边界（代码常量级）

```swift
enum SafetyLimits {
    static let pitchDownMax = 30.0      // 前屈软上限（硬顶 40°）
    static let pitchUpMax = 20.0        // 后伸软上限（硬顶 30°）
    static let yawMax = 40.0            // 旋转软上限（硬顶 45°）
    static let rollMax = 30.0           // 侧屈软上限（硬顶 40°）
    static let warnSpeed = 30.0         // °/s，超过提示减速
    static let rejectSpeed = 60.0       // °/s，判为甩头不计分
    static let maxExtensionHold = 5.0   // 秒，持续后伸上限
    static let sessionMax = 90.0        // 秒，单局硬上限
}
```

- 首次进入游戏展示一次性提示：「有颈椎病史、手麻、头晕请先咨询医生；游戏中任何不适请立即停止」。
- 任何玩法 PR 评审必须对照此表；新增动作必须先更新本表。

## 8. 明确不做

- 排行榜 / 社交分享 / 好友系统（单机开源，未来再议）
- 稀有度掉落、抽卡式奖励、内购
- 无限畅玩模式、"再玩一局"按钮
- 断签清零、内疚式推送、催促型通知
- 快速甩头类玩法（任何诱导角速度 >60°/s 的设计）

## 9. 技术风险与待验证

| 风险 | 应对 |
|---|---|
| chin tuck 在 AirPods 上的识别率（M4） | M1 阶段实测；备好降级方案（小幅点头蓄力） |
| 声效延迟体感 | 离散事件音为主；sonification 限慢速场景；真机听测 |
| 像素画资产工作量 | 先用 box-shadow / 程序生成像素画（设计稿已验证该路线），后续再换美术 |
| 游戏窗内实时渲染性能 | Canvas 2D 足够 8-bit 游戏；先做一个游戏验证再铺量 |
